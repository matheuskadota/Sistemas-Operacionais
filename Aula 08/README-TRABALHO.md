# Aula 08 — Virtualização com FreeBSD

Este diretório complementa o conteúdo da Aula 08 com uma implementação prática utilizando **FreeBSD 15.1-RELEASE** como sistema convidado no VirtualBox.

A escolha do FreeBSD foi intencional: em vez de repetir a instalação de uma distribuição Linux já conhecida, a atividade foi utilizada para estudar outro sistema Unix-like e comparar sua arquitetura e administração com distribuições Linux.

## Conteúdo

- [`Manual FreeBSD/README.md`](Manual%20FreeBSD/README.md) — instalação, configuração, troubleshooting e validação da VM.
- [`Linux vs FreeBSD/README.md`](Linux%20vs%20FreeBSD/README.md) — comparação técnica entre distribuições Linux e FreeBSD.

## Resultado

A VM foi concluída com:

- FreeBSD 15.1-RELEASE;
- XFCE 4.20;
- VirtualBox Guest Additions;
- resolução em tela cheia;
- clipboard bidirecional;
- Firefox;
- Fastfetch automático;
- terminal configurado;
- recuperação por Single User Mode testada.

As capturas utilizadas na entrega podem ser armazenadas em `Manual FreeBSD/imagens/`.
